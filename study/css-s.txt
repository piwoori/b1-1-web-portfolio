/* =========================
   CSS Variables
========================= */
1. :root {}
- root
  - 문서의 최상위 요소
  - HTML에서는 <html>을 가르킴
  - <html>에 직접 스타일을 주기보다는 CSS에서 전체적으로 사용할 변수들을 한 곳에 선언하기 위함
- --color-bg
  - --가 붙은 것들: CSS 변수
  - 그 변수들을 가져올 때는 var() 사용

2. [data-theme="dark"] {}
- [data-theme="dark"]
  - 속성 선택자
    - data-theme이라는 속성의 값이 "dark"인 HTML 요소 선택
- 다크모드에서 바꿀 필요가 있는 변수만 덮어씀

/* =========================
   Reset
========================= */
3. * {}
- *
  - 전체 선택자
    - HTML의 모든 요소에 적용
    - div, p, h1, button, section 등 전부 해당
- box-sizing: border-box
  - 요소의 width/height를 계산하는 방식을 정하는 속성
  - border-box
    - padding과 border까지 width 안에 포함(전체 크기를 맞추는데 용이)
- margin: 0, padding: 0
  - 브라우저는 원래 HTML 요소마다 기본 여백을 가지고 있음
  - 기본 여백을 없애고 원하는 여백 0으로 지정

4. html {}
- scroll-behavior: smooth
  - 페이지에서 위치를 이동할 때 부드럽게 이동 됨

5. body {}
- 페이지 전체의 기본 디자인을 설정
- font-family: Arial, sans-serif
  - rial을 우선 사용
  - 사용할 수 없으면 브라우저의 기본 sans-serif 계열 폰트 사용
- font-size: var(--font-size-base) ...
  - 위에서 선언한 변수를 글자 크기로 설정
  - 그 외도 동일

6. a {}
- 기본 HTML 스타일을 정리하는 부분
- color: inherit
  - inherit
    - 부모 요소의 값을 물려받게함
- text-decoration: none
  - 기본 밑줄 제거

7. ul {}
- <ul>의 스타일을 정리하는 부분
- list-style: none
  - 리스트의 기본 • 점 제거

8. img {}
- <img>의 스타일을 정리하는 부분
- max-width: 100%
  - 이미지가 부모보다 커지지 않도록 최대 너비를 100%로 제한
- display: block
  - 이미지가 블록 요소처럼 배치되게 함

/* =========================
   Common
========================= */
9. section {}, h2 {}
- <section>의 스타일을 정리하는 부분
- max-width: var(--max-width)
  - 아무리 넓은 화면에서도 최대 1200px까지만 커지게 함
- margin: 0 auto
  - margin: 상하 좌우의 형식
  - auto를 좌우에 주면 브라우저가 남는 공간을 양쪽에 똑같이 배분
  - 요소가 화면 가운데 정렬하기 위함
- padding: var(--spacing-xl) var(--spacing-md)
  - section끼리 위아래 공간을 남기기 위함
- h2 {}도 동일

/* =========================
   Header / Navigation
========================= */
10. .header {}
- <h2>의 스타일을 정리하는 부분
- position: sticky
  - sticky
    - 원래 위치에 있다가 스크롤하면서 지정한 위치에 도달하면 거기에 붙어 있는 방식
- top: 0
  - 트폴리오를 아래로 내려도 내비게이션이 위에 계속 보이게 함
- z-index: 1000
  - 요소들이 서로 겹쳤을 때 누가 위에 나타날지 정하는 값
  - 헤더가 스크롤 중 다른 콘텐츠 뒤로 숨어버리지 않도록 높은 값 부여
- transition:
  - CSS 속성값이 바뀔 때 갑자기 바꾸지 말고 애니메이션처럼 부드럽게 바꾸라는 뜻
  - 기본 형식: transition: 바꿀속성 시간 변화방식
  - ease
    - 시작과 끝의 속도를 자연스럽게 조절하는 방식

11. .header.scrolled
- header 클래스와 scrolled 클래스를 동시에 가지고 있는 요소
- 띄어쓰기 유무가 중요
  - .header.scrolled: 한 요소가 header와 scrolled 둘 다 가지고 있음 
  - .header .scrolled: header 요소 안쪽에 있는 scrolled 요소
- box-shadow: 0 2px 12px rgba(0, 0, 0, 0.08)
  - 0     → 좌우 이동
  - 2px   → 아래쪽 이동
  - 12px  → 흐림 정도
  - rgba  → 그림자 색 + 투명도
  - 스크롤하면 헤더 아래쪽에 은은한 그림자가 생겨서 콘텐츠와 구분

12. .theme-toggle {}
- cursor: pointer
  - 마우스를 올렸을 때 손가락 모양 커서로 바꿈
- display: flex
  - 해당 요소가 Flex Container가 됨
- align-items: center
  - 세로 가운데 정렬
- justify-content: center
  - 가로 가운데 정렬
- justify = 무조건 가로, align = 무조건 세로는 아님
- flex-direction: row으로 설정해 지금은 가로/세로
- 둘 다 center니까 가로·세로 정중앙 정렬
- 🌙/☀️ 아이콘을 중앙에 맞추 위함

13. .nav {}
- justify-content: space-between
  - space-between
    - 양 끝에 요소를 붙이고 그 사이 공간을 벌려줌
  - 헤더에서 로고와 메뉴 영역을 양쪽으로 배치하는 데 사용

14. .nav-menu {}
- display: none
  - 화면에서 숨김
- position: absolute
  - absolute
    - 요소를 일반적인 문서 배치 흐름에서 빼고 특정 위치에 배치
    - 모바일 메뉴를 헤더 아래에 펼쳐야 하니까 사용
- top: 100%
  - 기준이 되는 영역의 높이만큼 아래쪽에서 시작
- left: 0, width: 100%
  - 왼쪽 끝부터 시작해서 전체 너비를 차지
- flex-direction: column
  - 주축을 세로 방향으로 변경
- gap: var(--spacing-md)
  - Flex/Grid 안에 있는 자식 요소 사이의 간격 설정
  - 자식들 사이에만 일정한 간격 생성

15. .nav-menu a:hover {}
- :hover
  - 마우스를 올려놓은 상태

16. .menu-toggle {}
- display: block
  - 요소를 블록 요소처럼 표시
